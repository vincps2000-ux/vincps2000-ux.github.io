Build Small RLE(https://en.wikipedia.org/wiki/Run-length_encoding) Algorithm in Python.

Core idea, Count a Char like this, if it turns up multiple times: XXXee --> 3X2e

Just iterate through text, if Char matches previous char, count up.
If it doesnt, Add result, and count with new char.
